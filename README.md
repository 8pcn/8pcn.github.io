# 8PrinciplesCN-test｜政治原則測試

一個用於探索個人政治傾向的中文測試。

與傳統政治測試傾向於將受測者歸入某種現成的意識形態不同，本測試從八項政治原則出發，通過兩兩比較，考察不同原則在個人判斷中的相對優先級，尋找唯一的最高政治原則。

測試不預設某種立場優於另一種立場，也不試圖用單一標籤概括一個人的全部政治觀點。結果主要呈現各項原則之間的相對傾向，並保留不同原則相互影響、難以簡單歸類的情況。

它更關注你在不同價值發生衝突時如何取捨，而不只是你認同哪些政治口號。

測試結果僅供自我反思與討論，不構成對個人政治立場的權威判定。

# 8PrinciplesCN-test｜政治原则测试

一个用于探索个人政治倾向的中文测试。

与传统政治测试倾向于将受测者归入某种现成的意识形态不同，本测试从八项政治原则出发，通过两两比较，考察不同原则在个人判断中的相对优先级，寻找唯一的最高政治原则。

测试不预设某种立场优于另一种立场，也不试图用单一标签概括一个人的全部政治观点。结果主要呈现各项原则之间的相对倾向，并保留不同原则相互影响、难以简单归类的情况。

它更关注你在不同价值发生冲突时如何取舍，而不只是你认同哪些政治口号。

测试结果仅供自我反思与讨论，不构成对个人政治立场的权威判定。
